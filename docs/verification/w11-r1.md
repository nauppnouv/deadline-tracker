## Regression qua HTTP thật và MariaDB

`AttachmentHideAuthorizationTest` chạy embedded server trên loopback/cổng ngẫu nhiên, Java HttpClient với session đăng nhập thật, CSRF từ HTML render và MariaDB Testcontainers digest ghim của repo. Không dùng MockMvc hoặc persistence mock trong bộ này.

Tám JUnit gồm: tráo group Owner/Member; Member đúng nhóm; sai task hoặc file không tồn tại; outsider dù là uploader; thiếu CSRF; Owner đúng nhóm; uploader; attachment có group không khớp task. Ca sai task/file có hai request, không đếm thành hai JUnit.

Các request bị từ chối so toàn bộ row attachment, row pin và byte blob trước/sau. Hai ca hợp lệ xác nhận ghi hidden_by/hidden_at, bỏ pin, giữ row/blob/hash/size và download sau ẩn trả404. Fixture dữ liệu group không nhất quán chỉ tạo trong DB thử để kiểm fail-closed, không sửa migration lịch sử.

Trước test, kiểm effective JDBC endpoint (đã bỏ query nhạy cảm), `DATABASE()=deadline_test`, `CURRENT_USER()=deadline_test@%`, MariaDB11.8.9 và container id. Testcontainers reuse tắt, biến DB môi trường bị gỡ, attachment root và java.io.tmpdir nằm trong evidence root riêng. Không kết nối DB đang dùng.
